Using Gmail? (Recommended)

Since these emails are just for you as the admin, the simplest option is connecting your own Gmail account rather than a separate mail provider:

  1. Go to myaccount.google.com/apppasswords (requires 2-Step Verification to be turned on for your Google account).
  2. Create an App Password for "Mail".
  3. Below: set Host to smtp.gmail.com, Port to 587, Username to your full Gmail address, and Password to the App Password (not your normal Google password — Google blocks that for this).

Links we email (someone's purchases, their downloads, their bookings) are built from the site address on the Dashboard — one setting, shared with Stripe's return address and callbacks, so a change of domain only has to be made once.

Set to Gmail's server by default. Using another provider? Outlook is smtp.office365.com, and most hosts publish theirs as “SMTP server”.

Leave this blank and enquiries go to the “From” address above, which is what almost everybody wants. Fill it in only if enquiries should reach a different inbox from the one the site sends as.
