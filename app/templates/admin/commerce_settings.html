How long things stay good for

Session credits

Applies to sessions bought from now on. Sessions someone has already paid for keep whatever term they were sold under.

Downloads

Nobody hosts a file forever, so a buyer is told how long they have and can save it in time. Applies to files bought from now on — anything already sold keeps the term it was sold under. Choosing Never is a promise to keep the file up indefinitely.
