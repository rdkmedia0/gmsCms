Import Template Package

Upload a .zip exported from "Export" above (from this site or another install running this same CMS). Installs its theme immediately; if it also carries page content, that's merged into your site's matching pages the same way "Load Content" above works. If you already have that template you'll be asked what to do: Overwrite keeps one template and puts the uploaded files in place of the ones with the same name, Keep both installs this one beside the original under its own numbered name, and Cancel changes nothing. A built-in template is reinstalled on every restart, so it can't be overwritten — for those, Keep both is the only choice offered.

Save current site as a new template

Captures the active template's look, layout, and every page's content as a brand new, independent template — saved into your library immediately, right alongside built-in and imported ones. This is also your "get back to this later" point: save one before a risky change, then activate it again to restore everything. Leave the name blank to use a timestamped default you can rename later; exporting a .zip (above) stays a separate action.
